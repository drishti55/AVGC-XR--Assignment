# Knowledge base sources

The knowledge base (`backend/data/passages.json`) holds **18 passages** from the
**Garuḍa Purāṇa Sāroddhāra**. This is Naunidhirāma's 16-chapter compendium of the
*Preta Khanda* (Uttara Khanda), the part of the Garuḍa Purāṇa about death, karma,
the after-death journey and liberation.

Each passage has three separate layers, and each layer credits its own source.

| Layer | Edition | Status |
|---|---|---|
| Sanskrit (मूल) | Gita Press, Gorakhpur, *गरुडपुराण-सारोद्धार (सानुवाद)*, book code 1416 | © Gita Press. Short excerpts, credited, for non-commercial educational use |
| Hindi translation | Same Gita Press 1416 edition | As above |
| English translation | Ernest Wood & S. V. Subrahmanyam, *The Garuḍa Purāṇa (Sāroddhāra)*, Pāṇini Office, Allahabad, 1911 (Sacred Books of the Hindus, vol. 9) | Public domain |

**Online copies used**

- Gita Press 1416: <https://archive.org/details/1416-garud-puran-saroddhar> (PDF and OCR text)
- Wood & Subrahmanyam: <https://sacred-texts.com/hin/gpu/index.htm> (transcription)
- Printed check for the English: <https://archive.org/details/sacredbooksofthehindusvol09thegarudapuranasaroddhara1974_202002> (1974 SBH reprint)

## Why these editions

- **Same text in all three languages.** Both editions translate the Sāroddhāra and
  follow the same 16 chapters. Their verse numbers matched for all 18 passages, so
  `verse_ref_en` and `verse_ref_sa` are equal. Both fields are kept anyway, so any
  later passage whose numbering differs can record each edition's own reference.
- **Good coverage of the assignment's sample questions.** The passages cover karma,
  the soul, good deeds and giving, the journey after death, and liberation.
- **Can be identified and checked.** Each passage records chapter, verse range and
  page numbers for both editions, so anyone can find it in the scans.

## How the passages were prepared

No scripture text was typed from memory or generated by AI.

1. **English** was taken from the sacred-texts transcription, keeping the edition's
   verse labels (for example `15-17.`). It was then compared word by word against the
   OCR of the printed 1974 reprint. That found two transcription typos, which were
   corrected and noted in each passage's `notes` field:
   - "mike" → "make" (GPS-05-055)
   - "leave faith" → "have faith" (GPS-08-110)
2. **Sanskrit and Hindi** were taken from the archive.org OCR of the Gita Press 1416
   scan, split into verses by the `॥ n ॥` markers.
3. **Every passage was proofread against the page images.** The page for each verse
   was found from the verse markers in the PDF and checked visually. Common OCR
   errors were fixed to match the printed page:
   - `5` for avagraha `ऽ`, and `:` for visarga `ः`
   - dropped reph in `तार्क्ष्य`
   - missing anusvāra (`धर्मं`, `कर्मोंके`)
   - garbled conjuncts (`ईदृशी`, `भक्त्युपहृतमश्नामि`, `पूर्वादिभिस्त्रिभिर्मार्गैर्ये`)
   - footnote text that had leaked into the Hindi (GPS-05-055, GPS-16-005)
4. `backend/scripts/validate_kb.py` enforces the structure:
   - 15–20 passages, with unique IDs
   - required fields present
   - Sanskrit and Hindi actually in Devanagari script
   - every source reference resolves
   - no placeholder text left in

## Passage ID scheme

`GPS-<chapter>-<first verse>`. For example, `GPS-02-015` is Sāroddhāra chapter 2,
starting at verse 15.

## Limitations

- **Saroddhara numbering only.** The chapter and verse numbers belong to the
  Sāroddhāra, not to the full Garuḍa Purāṇa's Preta Khanda; the `khanda` field says so.
- **The Hindi is a translation.** It is Gita Press's rendering, often more expansive
  than the verse, and sometimes with words added in brackets.
- **Gita Press edition year not verified.** The archive.org copy doesn't show it, so
  `year` is left `null` rather than guessed.
